# E-commerce Growth Pack

This pack contains the vertical-specific configurations for E-commerce clients.

## Included Assets
- **ICPs**: D2C Shoppers, Cart Abandoners, VIP Customers.
- **KPIs**: ROAS, AOV (Average Order Value), Cart Abandonment Rate.
- **Workflows**: Shopify Cart Recovery, Klaviyo Retention Loops, Facebook Ad Adjustments.
- **Constraints**: Maximum daily ad spend limits, strict brand voice rules for SMS.
